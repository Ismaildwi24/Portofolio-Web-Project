Tentang Saya

Saya memiliki ketertarikan yang besar terhadap dunia data. Berawal dari rasa penasaran tentang bagaimana data dapat diolah menjadi insight strategis untuk bisnis, saya mulai membangun fondasi analitik menggunakan Python. Melalui portofolio ini, saya mendokumentasikan perjalanan eksplorasi saya sekaligus membagikan berbagai proyek analisis dan visualisasi data yang sedang saya kembangkan. Saya percaya, analisis yang tajam baru akan benar-benar berdampak jika dikomunikasikan dengan jernih.

Melalui portofolio ini, saya ingin mendokumentasikan perjalanan belajar saya serta memamerkan beberapa proyek analisis dan visualisasi data yang sedang dan akan saya kerjakan. Saya percaya bahwa komunikasi yang jelas melalui data sama pentingnya dengan analisis itu sendiri.
